## Getting started

### What this editor does

It creates and edits quests for Monster Hunter 3 Ultimate (3DS, European or North American version; choose yours in Settings > Game version) on Citra or on a real 3DS. Custom quests are written into the game's event-quest slots (3 packs of 20 quests, plus the pack of challenge quests), where the game lists them like its own event quests. It can also edit the game's own Village and Port quests as a mod folder (the ROM is never changed).

### Make a custom event quest

1. Close Citra (it rewrites the quest files when it exits).
2. In-game quests > Event quests: select a free slot and press 'New quest here...'.
3. Pick a quest to copy - preferably one on the same map, with similar monsters - and give it a name.
4. Edit the tabs: General, Monsters, Supply Box, Rewards, Text.
5. Press Save (Ctrl+S). A full backup is made first.
6. Start the game: the quest is in the event quest list.

Why copy a quest on the same map? The end of a quest file holds data that depends on the map (the places of the small monsters, a block that is not understood). A copy keeps it consistent.

### Event quests or challenge quests

Pack 4 holds the game's Challenge quests (61000+). A quest placed there shows up in the Challenge quest list, not with the event quests. Use packs 1-3 for custom event quests.

### The five pages

In-game quests: the quest files of your save. Tabs: Event quests (packs 1-3, where custom quests go), Challenge quests (pack 4) and Backups. Actions: Edit, New quest here, Put a quest here (from the library, a file or a backup), Duplicate, To library, Export, Clear slot.

Quest library: quests kept on your PC (library/*.mh3uq). Edit them, share the files, and send them into a game slot with 'To game'.

Base game: optional. The game's own Village and Port quests, saved as a Citra mod. Needs the extracted romfs folder. Install the mod into Citra with the button on that page; on a real 3DS copy the output folder into luma/titles/<title id>/romfs.

Monster pack: optional ROM hack that lets large monsters start on maps the game does not allow (see its own tab in this Guide).

Guide: this page.

### Keys, themes, developer mode

Ctrl+S saves. Ctrl+F searches the tab you are looking at (labels, values, list rows and the (i) texts); on a quest list it jumps to the search box. All text can be selected and copied. 'Undo changes' puts the quest back as it was when you opened it. The checks badge in the top bar warns about mistakes that can stop a quest from loading.

Themes: Moga Parchment (light, default) and Tanzia Night (dark), in Settings.

Developer mode shows internal numbers (ids, type codes, raw fields) and the Advanced tab. Keep it off for normal editing.

### Pictures

The monster, item and map pictures come with the editor (folder assets). If they are missing, or you want them rebuilt from your own extracted game, use Settings > 'Rebuild the pictures from my game...' (a few seconds; needs the Pillow package, 'py -m pip install pillow'; item icons also need the game's exefs/code.bin). Without pictures everything works, with empty pictures.

### Real 3DS

Back up the game's extra data with Checkpoint (or JKSM), copy it to your PC, choose that folder (In-game quests > Change folder...), edit and save, then restore it to the 3DS with Checkpoint. Custom supply boxes and base-game edits are romfs mods: copy their output folder into luma/titles/<title id>/romfs. Title id: 00040000000B1D00 (EU) or 00040000000AE400 (US).

## General tab

### Star rank

Star rank shown on the quest board. It is only a label: how strong the monsters are is set in the Monsters tab.

### Map

Where the quest takes place. The game lets each large monster start only on some maps; on another map it simply does not appear (the editor warns you). The Monster pack page can lift that limit (ROM hack). When you create a quest, copy one that already uses the same map: the hidden data at the end of a quest (small monsters, events) depends on the map.

### Time limit

Time limit in minutes. The game's quests use 50 minutes (348 quests) or 30 minutes (16 quests, mostly arena and special fights).

Tested in the game: up to 98 minutes the clock counts down normally (51 and 98 were tried); from 99 minutes it is FROZEN, so the quest never times out (99 and 120 were tried). Values between 99 and 120 are expected to behave the same; 135 is reported by players to freeze it too but is untested, and how high a value the game can take is not known. The 'Frozen clock' box sets 99, the lowest frozen value.

The 'Frozen clock' box sets 99 minutes, the lowest frozen value.

### Fee, Reward, Penalty

Fee: Fee: zenny paid to accept the quest.  
Reward: Zenny earned when the quest is completed.  
Penalty: Zenny taken from the reward each time a hunter faints. In every quest of the game it is one third of the reward (rounded up).

The (i) next to each shows what the game's quests of the same star rank use.

### HR points

HR points: Hunter Rank points earned when the quest is completed.  
HR points on failure: Hunter Rank points given when the quest fails. 330 of the game's 365 quests give 15, the others 0.

### Objectives: pattern

How the two objectives combine: one objective only, both objectives must be done, or either objective completes the quest.

### Objectives: type, target, how it is counted, count

What the hunter must do. Hunt = slay or capture, Capture = capture only, Slay = kill only, Deliver = bring an item to the red supply box. Target: the monster (or the item to deliver).

How it is counted (for hunts):  
· The quest's only large monster: a quest with a single large monster.  
· A specific monster of the quest: used when the quest has 2 to 4 large monsters; the Target names ONE of them. The targets are the monsters of the LAST group to arrive (see 'How the monsters arrive' on the Monsters tab); the quest is won as soon as the targets are slain, even if another monster that is not a target is still alive.  
· Copies of it, one after another: N copies of the same monster that arrive in succession.  
· Small monsters (count): hunt that many small monsters.

Normally you do not need to touch these: the Monsters tab sets them for you.

Target: The monster. Pick one that has spawn data on the quest's map.

Count: How many. The game's own quests write it like this: 'Hunt 2 Arzuros' (Double Jeopardy), 'Slay 12 Altaroth' (Bug Hunt), 'Deliver 3 Unique Mushrooms' (Tutorial 1).

'Set the objectives from the monsters' writes objectives A and B the way the game's multi-monster quests do. The Monsters tab does it for you whenever you add, remove, replace or reorder a monster.

### Environment: Stable or Unstable

Stable: only the monsters you listed are in the zone. Unstable: other large monsters can also wander into the zone at random (the quest board shows 'Environment: Unstable'). You cannot choose WHICH monsters: the game keeps a roaming-monster list for each zone, outside the quest file (it was not found in the game's files), and the quest only holds the chance, the maximum and a list number. The editor therefore reuses the settings of a game quest on the same zone. The monsters named on the wiki for a quest are not necessarily the roaming ones.

To have a monster present for sure, add it as a large monster (and use the arrival patterns).

Chance of roaming monsters: Chance in percent that roaming (stray) large monsters show up. 0 = the environment is Stable; above 0 it is Unstable (checked on 250 game quests).  
At most at the same time: Most roaming monsters at the same time (1 or 2).  
'Roaming monsters like another game quest...' copies the roaming settings of a game quest on the same zone. Changing the map offers to replace the small monsters and the roaming settings with the new map's.

### Developer mode: other gameplay settings

Arrival pattern (start_param): ARRIVAL PATTERN of the large monsters (read in the order of their cards). 0 = all at the start; 1 = one after another; 5 = the first, then the other two together (3 monsters); 6 = the first two together, then the last one (3 monsters); 4 = the first, then two together, then the last (4 monsters); 8 = two together, then two together (4 monsters). Found by comparing the game's 100 multi-monster quests; the Monsters tab sets it for you. Values used by the game's 365 quests: 0 (326×), 1 (26×), 8 (6×), 6 (4×), 4 (2×), 5 (1×).

Gathering table (hagi_no): Which gathering / carving table the quest uses (not confirmed: the game uses 0 to 4 depending on map and rank). Values used by the game's 365 quests: 2 (107×), 1 (100×), 0 (95×), 4 (37×), 3 (12×), 1280 (1×).

Progress level (prog_no): Progress level of the quest. The game uses 0 or 2 in the Village, 1 in Port Low Rank, 3 in High Rank and 4 in G Rank.

Monster level (enemy_lv): Monster level override used by a few Village key quests (0 = normal). Values used by the game's 365 quests: 0 (338×), 17 (1×), 23 (1×), 24 (1×), 25 (1×), 27 (1×).

Special flag: Special quest behaviour (arena fights, Harvest Tours, final battles...). Meaning of each value not confirmed: keep the value of the quest you copied.

Flag + condition pairs used by the game, with example quests:  
21 + 0:  Save Moga Village!  
22 + 0:  Masked Robbery  
23 + 0:  Howl at the Moon  
24 + 0:  Conqueror of Land and Sea  
3 + 17:  Harvest Tour: Misty Peaks, Harvest Tour: Deserted Isle, Harvest Tour: Sandy Plains  
6 + 20:  Harvest Tour: Misty Peaks, Harvest Tour: Deserted Isle, Harvest Tour: Sandy Plains  
8 + 22:  Ring of the Golden Lune, Ring of the Silver Sol, Moonlit Tryst  
2 + 16:  Double Trouble  
5 + 19:  Throne of the Abyss

Special condition: Goes with the special flag above.

Special condition 2: Second special condition. Values used by the game's 365 quests: 0 (357×), 13 (4×), 14 (4×).

Cutscene (demo_no): Cutscene played at the start. 0 (none) in every quest of the game.

Roaming list settings: use roaming list (1 when the quest uses a roaming-monster list, 0 otherwise.) / second % (A second percentage next to the chance (10, 20, 30, 50, 80 or 100 in the game's quests). Purpose not confirmed.) / list number (Number of the roaming-monster list of the map. The lists live in the game, so only numbers that a game quest on the same map uses are safe.) / always comes (1 in a few quests whose roaming monster always comes (100 % / 100 %).)

Quest number: The quest's number. The game identifies quests by it, so two quests can never share a number. Event quests use 20000-29999 and challenge quests 61000-61999. New quests get the first free number automatically.

### Developer mode: Advanced tab

Category flags: Quest category bits. Bits 4 and 20 together cut monster HP to 55% (used by Grudge Matches and challenge quests). Other bits are only known by which quests use them.

The tab also lists every numeric field of the quest (double-click to edit) and the hidden data at the end of the quest, which is kept as it is. Internal pointer: Internal pointer value; keep as is.

## Monsters tab

### Large monsters: the cards

Each large monster has a card, numbered #1, #2, #3 in the order they are read. Change... picks another species. Copy from a quest... copies a monster with every setting from another quest: it is the safest way to get a working monster. Remove takes it out of the quest. The arrows ◀ ▶ reorder the cards. The game lets each monster start only on some maps; on any other map it skips the monster, which then never appears (tested in the game). The card says 'Appears on <map>' or warns you; the Monster pack page can add the missing maps. Up to 5 large monsters fit in a quest.

### Size % and Size like

Size in percent: 100 = normal size. The base game uses 100 everywhere except a few special quests; event quests use 121 to 125 for King Size monsters, and 20, 40, 88, 180 and 200 for tiny or giant ones.

Sets the monster's size in one click. No hidden 'enraged' or 'charged' setting was found in the quest file: the game's 'Clashing Fists!' Brachydios (124 %) and 'Descent into Hades' Stygian Zinogre (125 %) are King Size, which the wiki describes as 'always King Size, with increased health and attack'. So King Size plus higher Health and Attack is the closest the quest can get; whether such a monster starts the fight enraged or charged is not something this editor can set.

Sizes seen in the game's quests: 100 (almost everywhere), 121 to 125 (King Size), 20, 40 and 88 (small), 180 and 200 (giant). Everything except Normal also sets 'Size spread' to 0, as those quests do, so the size is fixed.

### Strength like, Health, Attack, Toughness

'Strength like' sets Health, Attack and Toughness (and the hidden stamina and size spread) to the typical values of the game's own quests of that hub and star rank.

Health: HEALTH. Not an HP value: a row (0-127) of the game's difficulty table. The row gives a multiplier applied to the monster's base HP.  
Attack: ATTACK. A row (0-127) of the difficulty table; the row gives how hard the monster's attacks hit.  
Toughness: TOUGHNESS. A row (0-127) of the difficulty table; the row gives how much of your damage the monster takes (lower = tougher). The same row also sets flinch and part-break resistance.

The line under each slider gives the real multiplier and the rank it matches. Above the hardest row that any game quest uses, the label is Nightmare: harder than anything in the game.

### Count

How many copies of this monster arrive one after another. The game uses 1 almost everywhere, and 3 (or 5) in the 'Hunt 3 X in succession' quests, which have a single monster card. To have several copies together or in waves, add several cards. (Shown only when the quest has a single large monster, or in developer mode.)

### How the monsters arrive

When the large monsters of the quest arrive, and which of them you have to slay to win. The game's own quests with 2 to 4 large monsters use exactly these patterns; the monsters are taken in the order of their cards (use ◀ ▶ on a card to reorder them).

The quest is won when the monsters of the LAST group are slain; the earlier groups have to be dealt with first, because the next group is brought in after them (assumed from the game's quests, not confirmed).

The game's own quests with these patterns bring the next group after the previous one. What exactly triggers it (the previous monsters being slain or captured) is assumed, not confirmed: please watch it in your first test. The editor writes the objectives itself so that they match (the targets are the last group). If you change the objectives by hand, a monster that is not a target stays optional: the quest ends without it.

### Small monsters

The small monsters that live in the zone. Each line is a species and the number of places where it can appear: the game keeps such a list in every quest, and the game's quests have 5 to 15 species on a map. Places are copied from the game's own quests on the same map, so they always suit the map. Replacing a species keeps its places.

Add a species, Change..., Remove: edit the list. 'Fill from zone and rank...': Copies the complete small-monster list of one of the game's quests on this map (you choose which, closest rank first) and sets their strength for the chosen rank. Everything stays editable.

Strength of all small monsters: Strength of the small monsters: rows of the same difficulty table as the large monsters (health / attack / toughness).

### Developer mode: per-monster details

Stamina: How fast the monster gets tired (stamina table). The game uses: Village 0, Port Low and High Rank 1, Port G Rank 2, Grudge Matches and Challenge quests 3.

Start type: Start position number of the monster on the map. 0 = the game's usual start (3 large monsters out of 4 in the game). The game keeps, for every monster and map, a short list of start areas and this number picks one: Rathian on the Deserted Island has 4 (areas 10, 2, 5, 4), Zinogre on Misty Peaks 3. The 'Start positions' button shows the area of each number, read from the game's code. A number past the end of the list is flagged by the checks.

Size spread: Size spread: which table decides how much smaller or bigger than 'Size %' the monster can be (this is what makes crowns possible). The game uses: Village 1, 10 or 13; Port Low Rank 1; Port High Rank 3 to 7; Port G Rank 18 to 28; Grudge Matches and Challenge quests 0 (fixed size).

Set type: 0 in every quest of the game (all 403 quests checked). Leave it at 0.

Nando2: Second difficulty value (purpose not confirmed). The game uses 0 in most Village and Port G Rank quests, 1 in most Port Low/High Rank and event quests. Keep the value of the quest you copied.

Main small-monster species: First of the two 'main' small-monster species (always one of the species of the quest's small-monster list). Developer mode only: the list on the Monsters tab keeps these in step. Second of the two 'main' small-monster species.

## Supply Box

### The supply box

The supply box at the base camp. Each set is a fixed list of items defined by the game; pick the one whose contents fit your quest.

'Choose another supply box...' lists the game's boxes; search for an item to find the boxes that contain it. 'Fill from zone and rank...' picks the box that the game's quests use on this zone at the chosen rank.

### Your own box

'Make my own box' copies the current box into a box of yours, where you choose every item (up to 40 different items, 99 of each) and give it a name. A quest does not contain its box, only a number: the editor uses one of the 10 box numbers that no game quest uses, and writes your items into a supply file for that number.

The files must be installed: the 'Install the supply files into Citra' button copies them into Citra's load/mods folder; on a real 3DS copy output/MH3U_Supply_Mod/romfs into luma/titles/<title id>/romfs (00040000000B1D00 (EU) or 00040000000AE400 (US)). Without the files the game opens the box it normally has under that number. Every player of a multiplayer quest needs the same files.

### My supply boxes (manager)

The 'Supply boxes' button at the top (also 'My supply boxes...' in the Supply Box tab) opens the manager: rename a box, edit its items, see which quests use it and whether it is installed in Citra, install it, remove its file from Citra, or delete the box. Deleting a box also removes its file from Citra, after listing the quests that use it (they will open the game's own box with that number). Boxes are kept until you delete them; there is room for 10.

### Developer mode: second supply delivery

Delivery set: Second supply delivery: which set is delivered (not fully confirmed). Values used by the game's 365 quests: 1 (203×), 0 (135×), 2 (26×), 3 (1×).

Time condition: Delivery condition based on time (not confirmed). Values used by the game's 365 quests: 0 (364×), 3 (1×).

Monster condition: Delivery condition based on a monster (not confirmed). Values used by the game's 365 quests: 0 (364×), 2 (1×).

Count: Count used by the delivery condition (not confirmed). Values used by the game's 365 quests: 1 (208×), 0 (153×), 2 (4×).

## Rewards and Text

### Reward tables A and B

Each line: an item, how many, and its chance in percent. At the end of the quest the game draws several times from the table. Table A is the main reward; table B is drawn separately.

Add..., Edit..., Remove and ▲ ▼ edit a table (up to 32 lines). The total chance of a table is shown under it.

### Fill from the quest's monsters and rank

Builds table A from the game's own quests: the materials of each large monster of the quest, then the other items the game gives at that rank and zone (armor spheres, charms, ores, bones, bugs...). Each item belongs to the few monsters whose quests give it, so shared materials go to the right monsters. The dialog says what it is based on. Everything stays editable.

### Text tab

The game stores every text in English, French, German, Italian and Spanish; the console language decides which one you see. Quest name, Objective text, Sub-objective, Failure conditions, Client and Description are edited per language; 'Copy this language to the 4 others' fills the other languages with the current one.

## Monster pack

### What it does

The game keeps, inside its program (code.bin), a table of the maps where each large monster may start a quest. A monster put on another map is silently skipped. Each monster's own file also holds its spawn areas, routes between areas and special moves for each map it knows. The Monster pack gives every large monster the maps it is missing: for each new map it borrows the start positions and map data of a 'donor' monster that lives there (same kind of habitat and size where possible), and adds them to the monster's tables. The result: 358 new monster/map combinations for 47 monsters.

### What it changes (ROM hack)

It is a mod, built on your PC from your own extracted game: 47 files romfs/arc/enemy/emNNN.arc, a 5 KB patch exefs/code.ips (only new start lists, written in unused space of the program, and one pointer per monster) and mhqe_monster_pack.json. Your ROM and your save are not modified; removing the mod (button 'Remove from Citra') brings the game back exactly. It can not be combined with another code.ips/code.bin mod.

### Left out

Ceadeus, Goldbeard Ceadeus, Jhen Mohran and Hallowed Jhen Mohran (siege bosses), and the siege maps Great Desert, Underwater Ruin and Tainted Sea. Small monsters are not concerned.

### How to use it

1. Settings: set your game version and choose the extracted romfs folder (exefs/code.bin must be next to it).
2. Monster pack page: 'Build the pack from my game' (a few seconds), then 'Install in Citra' (close Citra first). On a real 3DS, copy the content of the pack folder into luma/titles/<title id>/ and enable game patching in Luma.
3. Make your quest as usual: the monster card says 'thanks to the Monster pack'. Keep the start position to one the card offers (the checks say when a number does not exist for the borrowed start list).
4. Restart the game and test the quest.

### Risks

Only Zinogre on Sandy Plains was tested in the game. Every other combination follows the same rules but is untested: the monster may get stuck, move oddly, or the game may crash when the quest loads. Riskier: the water arenas (a monster that can not swim), Sacred Land and Tower, and Alatreon or Dire Miralis away from their own maps; the table marks them '+!'. Back up your save first.

### Multiplayer

Every player in a local game must have the same pack installed, or the others do not see the monster (or worse). Built from the same game version the pack is identical for everybody (the EU and US packs are even the same files): compare the fingerprint shown on the Monster pack page.

## Files and backups

### What the editor changes

1. Your save's quest files: quest1, quest2, quest3 (event quests) and quest4 (challenge quests), in
   C:\Users\<you>\AppData\Roaming\Citra\sdmc\Nintendo 3DS\<id0>\<id1>\extdata\00000000\<00000B1D (EU) or 00000AE4 (US)>\user
   (the exact folder is found automatically). This is the only game data written by an ordinary save.
2. Optional mods, written in the editor's own output folder and copied into Citra on request:
   output/MH3U_Supply_Mod/romfs (your own supply boxes) and output/MH3U_Quest_Mod/romfs (edited base-game quests), installed into <Citra>/load/mods/<title id>/romfs, title id 00040000000B1D00 (EU) or 00040000000AE400 (US).
   The Monster pack (ROM hack, only if you build and install it) goes into <Citra>/load/mods/<title id>/: romfs/arc/enemy (47 monster files), exefs/code.ips and mhqe_monster_pack.json.
3. Files next to the program: settings.json, custom_supply.json, backups/, library/, error_log.txt (only if something went wrong).

### What to back up yourself

Before the first save, copy your save's extra data folder (the 'user' folder above holding quest1-quest4) and, if you use mods, the folder <Citra>/load/mods/<title id>. On a real 3DS, back up the save with Checkpoint or JKSM. The editor makes its own backups too, but a copy you made yourself is the one that cannot be touched by a bug.

### The editor's backups

Every save first makes a full backup of quest1..quest4 (backups/full/) and keeps a separate copy of every quest it replaces, edits or clears (backups/quests/), so a single quest can be put back in its slot. backups/original/ keeps the very first version of each file and is never deleted. Restoring a backup backs up the current files first. Everything is listed in In-game quests > Backups.

### Good habits

Close Citra before saving. Test on Citra before a real 3DS. Keep one slot per experiment. Share quests as .mh3uq files from the library rather than the raw save files.

## Tested or not

### Confirmed in the game

Arrival patterns: 'one after another', 'the first, then the other two together' and 'the first two together, then the last' work as described; with 'all at the start' every monster is in the zone from the beginning and the quest ends when the target monsters are slain.  
Monster placement: a monster the game does not allow on a map is skipped (Zinogre on Sandy Plains never appeared); with the Monster pack it appears (Zinogre on Sandy Plains, Citra). The opposite case, a monster allowed on a map without its spawn data, crashes the game when the quest loads.  
Time limit: up to 98 minutes the clock counts down; from 99 minutes it is frozen.  
Environment: Unstable is shown on the quest board when the chance of roaming monsters is above 0.

### Read from the game's files, not seen in play

The meaning of most quest fields comes from comparing the game's own quests (the (i) texts say 'not confirmed' where that is all there is). Not every pattern that the editor allows appears in the game: the three-monsters-at-once pattern and the five-monster 'one after the other' follow the same rule but never appear in a game quest, so test them.

### Known limits

The monsters that roam an Unstable zone cannot be chosen: their list is stored in the game, not in the quest. There is no 'enraged' or 'charged' setting in the quest file: the game's 'Clashing Fists!' and 'Descent into Hades' use King Size monsters. The block at the end of an event quest that is not understood is kept unchanged.  
Versions: the European version was studied and tested. The North American version was compared file by file with it: same quest format and base quests, same monster files, only the program id, the save folder (00000AE4) and the 'us' folder of the base quests differ. Its event quest files could not be checked on a real US save yet.

### Not tested yet
